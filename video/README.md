# Gradient · a little direction

A 78-second, 1920×1080, 30 fps introduction made with **Remotion 4.0.539**. Every interface shot is recorded from the actual Gradient app at `http://localhost:3102`. Website screenshots and recordings are not rebuilt mockups.

## Deliverables

- `out/gradient-demo.mp4` — clean master with narration and original music.
- `out/gradient-demo-captioned.mp4` — the same film with open captions.
- `out/gradient-subtitles.srt` — separate, sentence-level subtitles.
- `out/gradient-thumbnail.png` — branded cover featuring the actual homepage.
- `out/Gradient-Remotion-Project.zip` — portable project including recordings and audio; excludes dependencies and raw intermediate files.

## Edit and preview

```sh
cd video
npm ci
npm run studio
```

Studio opens at `http://localhost:3200`. Select **GradientFilm**, then scrub the timeline. The `captions` composition prop controls the optional subtitles. `GradientThumbnail` is a separate still composition.

- `src/Film.tsx`: scenes, typography, framing, transitions, and on-screen claims.
- `src/style.css`: espresso, ivory, taupe, champagne visual treatment.
- `src/narration.json`: seven narration segments and their start times.
- `src/captions.json`: sentence-level subtitle cues.
- `public/captures`: actual browser recordings and reference stills.
- `public/audio`: original ambient bed and seven narration WAV files.

## Recreate captures

Start the production website from the repository root:

```sh
npm run build
npm run start -- -p 3102
```

Then, from `video/`:

```sh
npx playwright install ffmpeg
npm run capture
```

The capture script uses installed Google Chrome with a **fresh browser context**. It creates an illustrative `Alex · Demo` profile through the actual onboarding form. It does not read the owner's browser profile, import personal data, or manufacture completed lessons, job offers, or review records. A visible cursor follows the real automated pointer actions.

Set `GRADIENT_URL` to record a different running address. Set `ONLY=focus` (or another shot name) to refresh a single recording. Google Chrome and system FFmpeg are required. The current renderer uses `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`; edit `scripts/render.mjs` for another machine.

The actual review queue was inspected in its empty state. The film demonstrates the homepage's real, explicitly labeled recall practice preview, rather than fabricating a populated queue. Extra Today and onboarding recordings remain available for alternate edits.

## Audio and rendering

```sh
npm run audio
npm run typecheck
npm run preview:frames
npm run render
npm run render:captioned
```

The finished film uses **ElevenLabs George — Warm, Captivating Storyteller**, generated with Eleven Multilingual v2. All seven narration sections are complete, normalized, and aligned to the scene windows. Subtitles use the returned character-level timing. The ambient soundtrack is an original procedural composition generated by `scripts/audio.mjs`, with no third-party samples or music downloads. The original local speech workflow remains available as `npm run audio:local`.

## ElevenLabs narration

The ElevenLabs narration workflow is complete and included in the project. Store `ELEVENLABS_API_KEY` in the local `.env.elevenlabs` file (excluded from Git and the portable ZIP). Optionally set `ELEVENLABS_VOICE_ID` to a chosen narrator. Never place credentials in source files or share them in chat.

```sh
npm run audio:voices
npm run audio:elevenlabs
npm run render:captioned
npm run package
```

The ElevenLabs script selects an available premade narrative voice, uses the documented speech-with-timestamps API, caches generated segments to avoid repeated paid requests, and aligns the seven segments to their scene windows. It replaces the master audio while preserving the rendered picture. Captions are regenerated from ElevenLabs character timings. `public/audio/narration-provider.json` is created only after successful ElevenLabs generation and identifies the actual voice and model used. The included provider record confirms the voice and model used in the finished film.

### Finished voice track
